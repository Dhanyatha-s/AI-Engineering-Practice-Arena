## ✨ Features

- ✅ **300 scenario-based questions** — beginner to advanced
- ✅ **Zero API cost** — fully local evaluator, no LLM calls
- ✅ **Code editor** with Tab indentation support
- ✅ **Instant feedback** — concept keyword analysis, structure scoring
- ✅ **XP system** — track progress, earn XP per question
- ✅ **Dashboard** — track progress per track
- ✅ **Scorecard** — session history, pass rate, avg score
- ✅ **Streak counter** — stay motivated

## 🛠 Local Development

```bash
# Clone
git clone https://github.com/YOUR_USERNAME/ai-engineer-lab.git
cd ai-engineer-lab

# Install
npm install

# Run
npm start
```

Opens at http://localhost:3000

## 📦 Deploy

### Vercel (recommended)
```bash
npm install -g vercel
vercel --prod
```

### Netlify
```bash
npm run build
# Drag build/ folder to netlify.com/drop
```

### GitHub Pages
```bash
# Add your homepage to package.json first
npm run deploy
```

## 🏗 Tech Stack

- **React 18** — UI framework
- **Zero backend** — runs entirely in the browser
- **Local evaluator** — no API keys, no cost
- **localStorage** — persists your progress
